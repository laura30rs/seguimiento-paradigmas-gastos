# Sistema de Control de Gastos Personales

## 1. Descripción

Proyecto académico de Ingeniería de Software II que implementa
un sistema de control de gastos personales utilizando cinco
paradigmas de programación en Java.

## 2. Funcionalidades

1. Registrar un gasto.
2. Mostrar el listado de gastos.
3. Calcular el total acumulado.
4. Mostrar el gasto de mayor valor.
5. Filtrar gastos por monto mínimo.
6. Buscar gastos por concepto mediante una subcadena.

- Java.
- Java Swing para la interfaz gráfica.
- SQLite y JDBC para la versión declarativa.
- Git y GitHub para el trabajo colaborativo.

## 5. Estructura del proyecto

El código estará organizado en carpetas independientes
para cada paradigma. La carpeta docs/ contendrá la documentación
común y el soporte de consulta bibliográfica.

## 6. Pruebas

Las cinco versiones se validarán con el mismo conjunto de gastos
y los mismos resultados esperados.

## 7. Flujo de trabajo con Git

- main: versión estable.
- develop: integración de las implementaciones.
- feature/*: ramas independientes para cada paradigma.

Cada rama feature se integrará en develop mediante
un Pull Request revisado y aprobado por otra integrante.
